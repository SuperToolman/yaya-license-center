# 低代码开发工程师专属知识包

版本：2026-11-17。适用于具有开发合同查询、表单设计预检、集成自动化预检和审批流程配置工具的客户平台。

将本目录 `01` 至 `04` 四份 Markdown 分别上传至员工编辑页的专属知识库。README 是维护说明，无须上传。上传、移除知识会递增员工版本；请完成整套配置后让客户更新员工安装。此目录的文件不会自动同步到商品或客户实例。

员工提示词和推荐能力的代码来源为 `web/app/(operation)/ai-employees/lib/low-code-engineer.ts`，在员工编辑页点击“应用低代码开发工程师配置”，核对后通过正常保存流程发布。能力预设只选择当前运营平台目录中存在的能力，不会给客户补出尚未部署的工具。客户必须同时升级平台实现，并在新任务中使用新员工版本。

知识分工：产品合同负责组件类型、默认属性、节点参数和表达式规则；本包负责开发规范、案例和验收方法；客户知识负责客户制度。不要在本包维护一份重复的完整属性表。组件或节点变动先更新产品实现及生成合同，再检查案例是否需要修订。

这些案例描述设计方法，不是经过客户业务执行验收的现成模板。当前仍有能力边界：defined/html/tsx 和逻辑明细表设计写入、普通自动化启用/试跑、动态主管或升级策略等，须按实际工具合同判断。
