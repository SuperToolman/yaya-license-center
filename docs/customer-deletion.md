# 客户删除

客户表格的“更多”菜单提供“删除客户”。仅平台超级管理员可调用删除检查及删除接口。

- `GET /api/customers/{customer_id}/deletion-eligibility` 返回 `canDelete`、`blockers`，每类关联包含类型、名称、数量及最多 10 个记录标识。登录和下载凭证不返回敏感标识。
- `DELETE /api/customers/{customer_id}` 在 SQLite IMMEDIATE 事务中重新检查，无关联时仅删除客户自身；存在关联返回 HTTP 409，不修改任何业务数据。

检查沿实际业务关系递归遍历：客户 → 订单/收款流水/许可证/历史许可证 → 提成台账 → 结算批次，以及授权主体 → 应用发布、产品、上架记录、授权和下载凭证，同时检查官网客户会话。相同记录去重，循环关系不会无限递归。取消、过期、撤销、已销毁的记录也会阻止删除。不会沿共享商品、服务商关系扩大到无关客户。

存在关联时，管理员需自行按下级到上级清理数据，再点击“重新检查”。不会级联删除、自动解绑或自动清理会话。现有页面未提供删除入口的数据，需管理员通过维护工具自行清理。独立审计历史快照继续保留，不作为业务依赖阻止删除。检查失败时禁止删除。

新增业务表或关联时，应同步维护 `api/src/customer_deletion.rs` 中的关系图及其测试。
