# 客户、订单、授权与平台实例业务规则

实施日期：2026-11-10。

## 业务入口

在 `/customers` 的客户操作中打开“查看订单”“查看授权”或“查看平台实例”。全部进入同一个 HeroUI 客户业务模态框，使用概览、订单、授权、平台实例标签切换，不新增客户实例路由。平台实例仅超级管理员可管理。

订单中心处理交易，授权管理按客户汇总。授权管理不再把一笔订单签出的许可证当成独立客户授权。

## 数据关系与履约

- 一个客户有多笔订单，只有一个稳定的客户授权标识。
- 订单只记录本次购买的商品、金额与天数。首次购买必须包含平台；后续可单独购买模块、AI 员工或平台续费。
- 订单完成回款后，运营管理员或超级管理员执行“交付授权”。事务内累计旧权益、签名新许可证、生成版本并标记订单履约。同一订单重复提交返回同一许可证，不重复延长权益。
- 平台续费从原到期时间与当前时间的较大值开始顺延；模块和 AI 员工按各自原期限顺延。没有有效平台授权时不能单独增购。
- 已购买模块的期限独立保存。实际可用期限受到平台有效期限制，后续平台续费不会丢失模块预付期限。
- 授权商品数量固定为 1，期限为 1–36500 天。服务商品可独立下单，纯服务订单使用“确认服务完成”，不签发许可证。
- 混合服务与授权订单以授权交付完成本次订单履约；如需单独跟踪实施服务，拆成纯服务订单。
- 收款状态与履约状态分列展示。财务处理回款，运营交付授权，超级管理员管理实例及授权撤销。

## 授权版本

`customer_authorizations` 保存稳定授权及最新、已激活版本；`authorization_versions` 保存不可变许可证的版本关系；`order_fulfillments` 保证每笔订单只履约一次。

最新签发版本可能尚未应用。旧的已激活版本在新版本激活后标记为“已被替代”，保留签名与历史记录，不将正常版本更新称为“销毁”。旧许可证在中心校验时会被拒绝。多实例客户应逐个同步最新授权。

撤销最新授权会撤销该客户已有授权版本，清除已激活指针；历史记录保留。撤销不等同于删除容器或立即停止容器。

## 实例绑定及同步

创建实例绑定当前客户最新有效的平台许可证。后端核对客户归属、客户启用状态、有效期及平台权益，不能通过提交其他客户的许可证绕过限制。

新部署在 Web/API 健康检查后应用许可证。已有容器通过“同步授权”更新，不需要重建容器或数据卷。授权同步有独立状态、错误及任务历史；API 重启后执行中的同步标记为中断，可核对后重试。

同步使用精确容器 ID 和实例标签验证目标，在容器内验签，将配置持久化到 `/var/lib/yaya/config/license.json`，并向许可中心确认激活。不会使用需要用户登录的低代码设置接口，也不会在命令参数或日志中传递许可证。

`YAYA_PLATFORM_LICENSE_CENTER_URL` 必须是客户容器可访问的运营平台 API 地址。本地默认 `http://host.docker.internal:8779`；Docker 部署覆盖文件按 `API_PORT` 设置默认地址，也支持显式 HTTPS API 域名。新建容器增加 host-gateway；Linux 上旧容器如没有此域名解析，请配置其可访问的真实许可中心地址。

## 迁移

新增授权迁移和平台交付迁移 7，不修改既有迁移校验和。历史订单关联的许可证自动整理为客户授权版本，保留 JWT 原文，不恢复已经销毁的许可证。

已有实例的数据库记录不能证明容器实际应用了哪个许可证，因此初始显示“未绑定授权”。有有效客户授权且容器运行时，可点击“同步授权”完成绑定。无需删除既有实例或数据卷。

更新前使用 SQLite backup 生成一致性快照；回滚数据库时应配套回滚 API，不能仅删除迁移记录。

## 验收路径及验证范围

1. 客户中创建包含平台的首购订单，登记足额回款，交付授权；确认客户授权第 1 版。
2. 创建仅含模块或 AI 员工的增购订单，回款并交付；确认原权益保留，版本递增，订单金额仅为本次购买。
3. 创建平台续费订单并交付；确认平台期限顺延，模块原期限不丢失。重复交付同一订单不增加版本。
4. 客户业务模态框内创建实例；确认绑定当前客户最新许可证。已有实例执行同步授权，核对已应用版本。
5. 验证无有效授权、停用客户、跨客户许可证均无法创建实例；API 重启后核对同步中断提示。

已验证：Rust 后端 84 项测试通过；客户业务浏览器 3 项、平台实例 16 项、容器可观测性 2 项测试通过（平台实例最后一项在修复嵌套模态框测试选择器后单独复跑通过）；TypeScript 与相关 ESLint 检查通过。隔离 API、独立数据库、临时 Docker 容器与独立数据卷的授权实际同步通过，覆盖容器验签、配置持久化、中心激活、已应用版本回写，临时容器和卷已清理。该隔离测试未重新执行完整离线包发布和应用启动流程，也没有修改现有客户容器的授权。

当前开发环境数据库已生成一致性备份，API 重启后授权迁移 1、交付迁移 7 均成功，授权及客户列表接口已使用现有管理员会话只读核对，返回正常。
